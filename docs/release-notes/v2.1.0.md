Fixes for Shizuku connection problems reported by users, Android TV / Google TV support, and new optimizations suggested in [#1](https://github.com/cyb3rl00m/prune-debloater/issues/1).

## Fixed
- **"Timed out waiting for 15000 ms" (reported on Xiaomi HyperOS).** Prune's Shizuku helper process never started on some phones, so every change waited 15 seconds and failed. Nothing was changed on those phones. Prune now falls back to running commands through Shizuku's own process, the same path other Shizuku apps use.
- Prune checks the connection once before applying anything. If it can't run commands, it stops and says that nothing was changed.
- A failed disable no longer claims "Uninstalled for this user instead" when that didn't happen. Results now describe what really happened.
- "Authorize Prune in Shizuku" did nothing after tapping Deny once in Shizuku. Prune now detects this and explains how to allow it.
- "Get Shizuku" opened the app store first, and some store clients (Aurora Store) looped on it. It now downloads from Shizuku's GitHub releases first.

## New
- **Test connection** (Home → Set up): shows whether Prune can run commands, as which user, and through which Shizuku path. Please include it in bug reports.
- **Android TV and Google TV (experimental):** Prune appears in the TV launcher and works with the remote's D-pad. TVs are detected automatically; the TV home screen, TV Settings, setup and the infrared remote service are locked; voice search, remote pairing and remote firmware updates are marked high risk.
- **Display and effects:** refresh rate (adaptive, always maximum, cap at 60 Hz), window blur off, high contrast text.
- **Animation speed 0.25×.**
- **Storage maintenance:** runs Android's idle maintenance now (`sm idle-maint run`, includes fstrim).
- **Quick Settings tiles:** fast animations on/off and clear all app caches. They are recorded in History and can be undone there.

## Testing
- The release APK is now tested with the real Shizuku app (latest release) on an Android 15 emulator: authorization, Test connection, the fallback path, a disable/enable round trip and the Quick Settings tile.
- The release APK is tested on the Android TV emulator (API 34): listed in the TV launcher, opened and navigated with the D-pad only.
- Still no testing on physical hardware by the project. TV support has not been tried on a real Google TV Streamer or TV yet.

## Known limitations
- Some firmwares (Samsung One UI, for example) use their own refresh-rate setting and may ignore Prune's.
- On a TV, starting Shizuku is easiest from a computer on the same network (`adb connect <TV IP address>`).
- Focus highlighting on small buttons and chips is still faint on TV.

## Install
1. Download `Prune-2.1.0.apk` below and open it on the phone or TV.
2. Allow installing from your browser or file manager when asked.
3. Open Prune → Home → Set up, follow the Shizuku steps, then tap Test connection.

**Upgrading from 2.0.0 or 1.0.0:** install over it. Same signing key; history and settings are kept.

SHA-256 checksums are in `SHA256SUMS.txt`. Full details: [README](https://github.com/cyb3rl00m/prune-debloater#readme) · [Changelog](https://github.com/cyb3rl00m/prune-debloater/blob/main/CHANGELOG.md)
