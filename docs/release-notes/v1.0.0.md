First release of Prune, a debloater and optimizer for Samsung Galaxy phones (built first for the Galaxy S25 FE).

**Highlights**
- Four debloat levels: Minimal, Balanced, Aggressive and Extreme / Custom, each fully customizable
- Tell Prune which Samsung features you use (Wallet, Pass, Watch and Buds, SmartThings, DeX, Quick Share, Bixby, Health, Find My Mobile, Secure Folder, S Pen, Galaxy AI...): their packages are never selected
- Every package explained: name, package id, description, category, status, risk and recommended action
- Protected core: telephony, emergency calling, System UI, security, biometrics, Knox, Google Play Services and your current launcher, phone app, SMS app and keyboard can never be changed
- Review screen with the exact command behind every change; high-risk changes need an extra confirmation
- Every change verified by reading the state back from Android, recorded with its previous state, and reversible
- Restore center: undo per change or batch, restore original state, list of everything disabled on the phone, emergency ADB restore script
- Optimization center with a technical reason for every option: animation scales, background restriction for unused apps, battery exemptions, permission and notification audit, storage and cache trimming, screen time and battery estimates, app compilation
- Works without root through Shizuku (wireless debugging); root optional; ADB script export without either

**Install**
1. Download `Prune-1.0.0.apk` below and open it on the phone.
2. Allow installing from your browser or file manager when asked.
3. Open Prune → Home → Set up, and follow the Shizuku steps (about 3 minutes, no computer needed).

**Tested**
Unit tests, plus on-device tests on an Android 15 emulator that run Prune's real `pm`, `appops`, `deviceidle` and `settings` commands as the shell user and walk through the whole UI. Shizuku binding, root and Samsung-specific behaviour still need testing on a real Galaxy phone: please report what you find.

SHA-256 checksums are in `SHA256SUMS.txt`.
