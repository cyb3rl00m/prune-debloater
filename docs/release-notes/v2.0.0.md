**Prune is evolving!** Originally developed with Samsung Galaxy devices in mind, Prune is now a universal Android debloating tool. It detects your phone's manufacturer, model and firmware automatically and adapts its rules, features and setup steps to it.

## What's new

**Universal Android architecture**
- Device identity from Build fields and system properties, firmware detection, and one integration module per manufacturer. A generic Android integration works on every phone; unknown manufacturers can never crash Prune.
- The debloat engine (`pm`, `cmd appops`, `cmd deviceidle`, `settings`) is the same for every brand; integrations only add knowledge.

**Manufacturer integrations**
- Dedicated rules: Samsung (One UI), Google Pixel (stock Android), Xiaomi / Redmi / POCO (HyperOS, MIUI), Huawei (EMUI, HarmonyOS 2–4), Honor (MagicOS), OPPO / OnePlus / realme (ColorOS, OxygenOS, realme UI), Motorola (My UX).
- Detection and firmware names for Sony, Nothing, ASUS, vivo/iQOO, Tecno/Infinix/itel, Nokia/HMD, Lenovo, ZTE/nubia and LG (generic rules).
- Each brand's critical apps are locked: for example the Xiaomi Security app, permission manager and updater; Huawei Phone Manager; OPPO/OnePlus Security Center and permission manager.
- Google, Huawei and Honor service frameworks are detected independently. On a phone without Google services, HMS Core and AppGallery are locked.
- Setup steps adapt to the brand, including Xiaomi's "USB debugging (Security settings)" and ColorOS's "Disable permission monitoring".

**Package identification**
- Rule files per manufacturer (348 curated entries in 9 files) plus the full community manufacturer lists: 5,396 packages known, up from about 2,000.
- New risk level **Unknown** for packages in no database: never pre-selected, Custom only, extra confirmation.
- Installer detection recognises apps placed by partner preload installers.
- Duplicate apps: app types installed more than once (browsers, galleries, keyboards, app stores...).
- Region-specific variants are marked; entries can carry consequences and recovery instructions and be limited to Android versions or firmwares.

**Compatibility report** (tap the device card on Home)
- Manufacturer, model, Android version, firmware, integration and compatibility level; access tier, Shizuku and root status; supported and unsupported operations with firmware caveats; what already succeeded or failed on this device; known limitations. Shareable as text for bug reports.

**Fixes and improvements**
- Package labels are cached between scans.
- Feature answers saved by 1.0 keep working; features new in 2.0 count as "used" until you answer.
- The keyboard closes when you open a package from search.

## Compatibility (be honest about it)

| Level | Manufacturers |
|---|---|
| Fully implemented and tested | Android emulator (stock Android 15), where Prune's automated tests run |
| Partially tested | Samsung, Google Pixel |
| Experimental | Xiaomi / Redmi / POCO, Huawei, Honor, OPPO / OnePlus / realme, Motorola |
| Generic | Sony, Nothing, ASUS, vivo, Tecno / Infinix / itel, Nokia / HMD, Lenovo, ZTE / nubia, LG, any other Android 9+ phone |

No brand has been tested on physical hardware by the project yet. Brand detection and firmware parsing are tested with simulated devices; the debloat commands are tested on a real Android 15 system (emulator) as the same user Shizuku uses. Please share your compatibility report in an issue.

## Known limitations and issues
- Shizuku binding and root have not been verified on real hardware.
- Xiaomi needs "USB debugging (Security settings)" and ColorOS-based phones need "Disable permission monitoring" for permission, background and animation changes.
- Huawei, Honor and some Samsung packages refuse `disable-user`; Prune uninstalls them for the current user instead (reversible).
- Some firmwares restore system apps during updates.
- Battery estimates depend on the firmware's `dumpsys batterystats` format.
- HarmonyOS NEXT cannot run Android apps.

## Install
1. Download `Prune-2.0.0.apk` below and open it on the phone.
2. Allow installing from your browser or file manager when asked.
3. Open Prune → Home → Set up, and follow the Shizuku steps shown for your phone.

**Upgrading from 1.0.0:** install over it. Same signing key; history and settings are kept.

SHA-256 checksums are in `SHA256SUMS.txt`. Full details: [README](https://github.com/cyb3rl00m/prune-debloater#readme) · [Compatibility](https://github.com/cyb3rl00m/prune-debloater/blob/main/docs/COMPATIBILITY.md) · [Changelog](https://github.com/cyb3rl00m/prune-debloater/blob/main/CHANGELOG.md)
